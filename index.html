SkyPick 개인정보처리방침

시행일: 2026년 10월 28일

SkyPick(이하 "앱")은 위치 기반 날씨 정보를 음성으로 안내하는 서비스입니다. 본 개인정보처리방침은 앱이 어떤 정보를 수집·이용·보관하는지, 그리고 이용자가 어떤 권리를 가지는지 설명합니다.

1. 앱의 기본 구조 — 회원가입 없음

SkyPick은 회원가입·로그인 기능이 없습니다. 모든 설정값(알림 시각, 반복 요일, 성별/말투 선택, 커스텀 안내 문구 등)은 이용자의 기기 안에만 저장되며, 별도의 서버 데이터베이스나 이용자 계정으로 전송·저장되지 않습니다. 앱을 삭제하면 이 모든 정보도 함께 삭제됩니다.

2. 수집하는 정보와 이용 목적

항목수집 목적저장 위치
위치 정보(위도/경도) 현재 위치의 날씨·자외선지수·미세먼지 농도를 조회하기 위함 기기 내 메모리에서만 일시적으로 사용. 서버로 전송되지 않으며, 기기에 영구 저장되지 않음
알림 시각/반복 요일 설정 지정한 시각에 날씨 알림을 보내기 위함 기기 로컬 저장소(Jetpack DataStore)
성별·사투리·말투 선택, 커스텀 안내 문구 음성 안내 캐릭터 목소리와 멘트를 생성하기 위함 기기 로컬 저장소. 음성 생성 시점에만 서버로 1회성 전송(아래 3번 참고)
알림 진동 모드 등 기타 환경설정 이용자가 선택한 알림 방식을 적용하기 위함 기기 로컬 저장소

SkyPick은 이름, 전화번호, 이메일 주소 등 개인을 식별할 수 있는 정보를 수집하지 않습니다.

3. 외부 서비스로의 정보 전송

3-1. 음성 안내 생성 서버 (자체 운영)

음성 안내를 생성할 때, 안내할 문장(텍스트)과 이용자가 선택한 성별·사투리·말투 값만 자체 운영 서버(Firebase Functions)로 전송됩니다. 이 서버는 이용자를 식별하거나 요청 기록을 데이터베이스에 저장하지 않는 상태 비저장(stateless) 중계 서버이며, 받은 텍스트를 TTS(음성 합성) 업체로 전달해 생성된 음성을 그대로 돌려줄 뿐입니다. 위치 정보, 기기 식별자, 이용자 개인정보는 이 서버로 전송되지 않습니다.

3-2. 타입캐스트(Typecast) — 음성 합성(TTS)

위 3-1에서 서버가 중계한 텍스트가 음성으로 변환되는 과정에서 타입캐스트(네오사피엔스)의 TTS API가 사용됩니다. 전달되는 정보는 안내 문장 텍스트뿐이며, 이용자를 식별할 수 있는 정보는 포함되지 않습니다.

3-3. 기상청 공공데이터포털 / 한국환경공단 에어코리아

날씨·자외선지수·미세먼지 정보를 조회하기 위해 앱이 기기에서 직접 공공데이터포털 API를 호출합니다. 이 과정에서 위치를 기상 격자 좌표로 변환한 값이 조회 요청에 포함되지만, 이는 공공 기상 데이터 조회 목적에 한해 사용되며 별도로 저장되지 않습니다.

4. 접근 권한

권한사용 목적
위치(정확한 위치/대략적인 위치)현재 위치 기반 날씨 정보 조회
알림매일 정해진 시각에 날씨 안내 알림 발송
정확한 알람 예약설정한 시각에 정확히 알림을 울리기 위함
부팅 시 자동 시작 수신기기 재부팅 후에도 예약된 알림이 유지되도록 재등록
배터리 사용량 최적화 제외절전 모드에서도 예약된 시각에 알림이 정상 동작하도록 함(선택 사항)
진동무음/진동 모드일 때 알림을 진동으로 전달
인터넷날씨 정보 조회 및 음성 안내 생성 서버 통신

SkyPick은 위치 정보를 이용한 광고, 트래킹, 제3자 마케팅 목적의 데이터 판매·공유를 하지 않습니다. 백그라운드에서 상시로 위치를 추적하지 않으며, 날씨 조회가 필요한 시점(앱 실행 시, 예약된 알림 발송 시)에만 현재 위치를 1회 확인합니다.

5. 정보 보관 기간

위치 정보는 조회 즉시 사용 후 폐기되며 저장되지 않습니다. 기기 로컬에 저장되는 설정값(알림 시각, 음성 설정 등)은 이용자가 앱을 삭제하거나 기기 내 저장소를 초기화할 때까지 보관되며, 이후에는 복구되지 않습니다.

6. 만 14세 미만 아동의 개인정보

SkyPick은 만 14세 미만 아동을 대상으로 개인정보를 의도적으로 수집하지 않습니다.

7. 개인정보처리방침의 변경

법령이나 서비스 변경에 따라 본 방침의 내용이 변경될 수 있으며, 변경 시 본 페이지를 통해 고지합니다.
